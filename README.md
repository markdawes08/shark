# Shark

Shark is a Windows-first Direct3D 12 graphics, physics, and simulation engine.
Its first playable goal is an original small-island demo with a third-person
character, terrain traversal, shallow-water wading, and surface swimming.

The long-term feature ceiling is the observable single-player action-RPG
capability breadth of the original 2002 PlayStation 2 release of *Kingdom
Hearts*, implemented independently with modern practices and original content.
See [the engine plan](docs/ENGINE_PLAN.md) for scope and increment order.
